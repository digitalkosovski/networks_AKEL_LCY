# Networks AKEL - LCY

Network data about contacts between the Yugoslav and Cypriot communist parties in the 1960s and 1970s.

The data was produced on the basis of Yugoslav archival sources: 
* Archive of Yugoslavia, Fond of the League of Communists of Yugoslavia, International Commission, Cyprus.

The repository contains:
* A nodes file.
* An edges file.
* Sample visualizations from Gephi: a general view of the graph and two ego-networks (Veljko Vlahovic and Ezekeias Pappaioanou).

The data was initially storaged on a Heurist relational database. It was exported initially as a .gefx graph file, from which the nodes and edges file were created.
